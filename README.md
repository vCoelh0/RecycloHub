#  📖 Descrição do Projeto

O RecycloHub é uma plataforma web desenvolvida para facilitar o gerenciamento de pontos de coleta de resíduos eletronicos e incentivar a participação dos cidadãos no processo de descarte responsável.

A aplicação permite:

✅ Cadastrar e gerenciar pontos de coleta

✅ Registrar descartes feitos por usuários

✅ Acompanhar ranking de descartes

✅ Visualizar pontos de coleta com filtros e buscas

✅ Acessar funções específicas dependendo do tipo de usuário (cidadão ou administrador)

🎯 Objetivo Geral

Desenvolver uma plataforma que conecte cidadãos e gestores municipais/privados no processo de descarte de resíduos eletronicos, exibindo pontos de coleta, registrando descartes e fornecendo ferramentas administrativas para otimização da gestão de resíduos.
